# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-09-06

### Added

- Patient registration and authentication with JWT.
- Patient profile management.
- Professional management.
- Appointment scheduling and management.
- Professional medical schedule.
- Appointment status management.
- PostgreSQL database integration.
- Flyway database migrations.
- Docker Compose environment.
- Swagger/OpenAPI documentation.
- Actuator, Micrometer and Prometheus monitoring support.

### Infrastructure

- Integrated Angular/Ionic frontend with Spring Boot backend.
- Containerized frontend, backend and PostgreSQL services.
- MVP 1 consolidated as the first running increment of TeleMed IA.

### Notes

- This release corresponds to MVP 1 — Cut 1.
- Some planned functionalities remain outside the scope of this release and are not included in MVP 1.
